## 📌 About
This repo contains my journey from basic Python to building automated tools that solve real problems. Each project adds a new skill - from file handling to data visualization to scheduling bots.

## 🔥 Projects

### 1. Career Advice App - `app.py`
Console app that gives career advice based on age. Saves user data to `users.txt`.
- **Skills:** `input()`, `if-elif`, File Handling

### 2. AI Dashboard - `dashboard.py`
Reads `users.txt`, shows total users, average age & bar chart.
- **Skills:** Pandas, Matplotlib, Data Analysis

### 3. Job Matcher (ATS) - `job_matcher.py`
Checks your skills vs job requirements and gives ATS score.
- **Skills:** List matching, % calculation

### 4. Portfolio Website - `streamlit_app.py`
All 3 projects in one WEBSITE with 3 tabs. My first live website!
- **Skills:** Streamlit, Web App
- **Run:** `python -m streamlit run streamlit_app.py`

### 5. File Organizer Bot - `organizer.py`
Auto-organizes Downloads into Images / PythonFiles / TextReports.
- **Skills:** `os`, `shutil`, Automation

### 6. Daily Scheduled Bot - `daily_bot.py`
Runs organizer automatically every day at 2:44 AM. Real company-style cron job!
- **Skills:** `datetime`, `while True`, Scheduling
